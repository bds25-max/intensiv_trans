# Транскрибатор

Простой ноутбук для транскрибации русской речи из аудио и видео с помощью Whisper в Google Colab.

## Запуск

1. Откройте [ноутбук в Google Colab](https://colab.research.google.com/github/bds25-max/intensiv_trans/blob/main/transcribe_ru_colab.ipynb).
2. Запустите ячейку и загрузите аудио- или видеофайл.
3. Дождитесь распознавания: текст появится под ячейкой, а файл `.txt` скачается автоматически.

[Открыть файл ноутбука в репозитории](transcribe_ru_colab.ipynb)
